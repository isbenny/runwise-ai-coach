# WorkBuddy 桌面版安装

**复制安装指令 → 加载 Skill → 添加并信任 MCP → 授权账号 → 开始分析。**

本机 WorkBuddy 5.8.3 已验证 Skill、既有 Garmin 中国区只读适配器、COROS 官方 OAuth 与活动读取；独立新任务可以重新读取。其他版本、手机宿主和 Taxuspt 新账号须各自实测。

## 1. 加载稳跑 Skill

1. 从本版 Release 下载 `runwise-coach-skill-v0.1.1.zip` 及同名 `.sha256`，让 AI 核验校验和、安装位置与改动，再由本人确认。
2. 打开「专家·技能·连接器 → 技能 → 添加技能 → 上传技能」，选择 ZIP；查看安全检测结果并确认安装。保持默认权限，不开启完全访问或自动安装其他组件。
3. 在「已安装」确认 `runwise-coach` 已启用；新建任务，输入 `/runwise` 并选择它。文件存在或 AI 口头称成功不能代替这一步。

通用安装器使用 `.agents/skills`，不能假定 WorkBuddy 自动识别。优先官方导入；任务内手动安装使用 `<本人工作区>/.workbuddy/skills/runwise-coach`。不要套用 CodeBuddy IDE 或 CLI 的路径。

## 2. 选择手表，添加连接

在「连接器 → 自定义连接器 → 添加 MCP」中操作。让 AI 先展示差异并备份，保留其他连接；保存后只信任本人核对过的产品连接。该用户级入口可能供其他任务使用，需要本人确认访问范围。**加载 Skill 不会自动注册、信任或授权 MCP。**

### 佳明中国区

- **已有本人认证的只读 MCP：** 直接复用其绝对解释器、启动入口和本人专属缓存/实例，不重装、不复制或搜索他人 Token。若为既有 Coach MCP，离线读取工具是 `get_connection_status`、`get_coach_context`、`get_activity_report`；只读历史验收时在工具列表关闭 `sync_recent`。
- **没有已有连接：** 让 AI 按 [Garmin 适配说明](garmin-cn.md) 预览固定 Taxuspt 版本的独立安装，确认后执行。普通用户无需安装旧研发工程或数据库。只启 `get_activities`、`get_activities_by_date`、`get_activity`、`get_activity_splits`。这条新账号路径与旧适配器的成功分开验收。
- 本机配置使用真实绝对启动路径；公开示例不包含开发者路径、账号、密码或 Token。不要把登录命令设为 MCP 启动入口。
- **空缓存：** 明确提示“待本人认证，尚未读取训练数据”。由本人打开安全本机交互入口完成认证；WorkBuddy 命令工具无 TTY 时停止，不在对话中输入密码、验证码或 Token。参见 Garmin 说明中的 `scripts/garmin_auth.py`。
- 保存并信任后，核对实际工具与启用状态；仅写入配置文件不代表宿主已加载。缓存存在不代表远端仍有效；离线库读取不冒充新同步。

### 高驰中国区

在上述官方 MCP 编辑器**合并**以下条目，保留其他配置，不整体覆盖：

```json
{
  "mcpServers": {
    "runwise-coros": {
      "type": "streamableHttp",
      "url": "https://mcpcn.coros.com/mcp"
    }
  }
}
```

1. 保存并信任本人确认的连接，点击“连接”。
2. 由本人在高驰官方页面登录并完成 OAuth。不要填静态 Bearer，不向 AI 发送凭据；不安装 Garmin 库或额外代理。
3. 返回 WorkBuddy，核对已连接及实际工具。若仍显示需要认证，可在宿主连接处重新检查一次；报错就记录非敏感提示并停止，不循环登录。
4. 展开工具，仅启本次需要的活动读取。本机已发现 `querySportRecords`、`getActivityDetail`、`queryActivityLapData`、`queryCustomActivityLapData`。关闭课表创建、更新、安排训练、健康信息和 FIT 下载等无关能力；首次仅读一条有上限的摘要，不取 GPS。工具目录可能更新，以实际 schema 为准。

详细授权与数据口径见 [COROS 说明](coros-cn.md)。官方 OAuth 与佳明本机认证是两条独立流程。

## 3. 开始分析

新任务选中稳跑 Skill 后，发送：

> 读取最近一次真实训练和近期统计，区分事实、计算、推断、缺口与建议；根据我的比赛目标、可训练日和恢复情况，生成未保存的条件式课表草案。不要重新安装或登录，不给无依据的精确配速。

读取前展示范围、预算、保存内容以及必要摘要会送到所选 WorkBuddy 模型的用途，取得本人确认。数据不足先问最少缺项，不自行加量或加速。用户主动说“更新训练数据”才触发已确认范围的读取；无后台推送。

草案不等于正式课表。只有宿主有可靠私有持久存储、本人确认具体内容后才保存；旧只读 Coach MCP 不提供计划写入口，不能声称已保存。新任务应重新读取档案及训练，不用旧聊天记忆代替。

## 遇到问题先区分

| 看到的情况 | 下一步 |
|---|---|
| 没有 Skill 或 `/runwise` 菜单项 | 用官方导入确认已安装并启用，再开新任务；不要只检查文件是否存在。 |
| Skill 可用，MCP 不在列表 | 通过官方设置保存本产品条目，核对当前用户路径，再确认信任；保留其他配置。 |
| Garmin 缓存为空或失效 | 待本人在安全本机入口认证；不索取聊天密码、不循环重登。 |
| COROS 需要认证或回调失败 | 回到官方连接入口检查一次；仍失败就停，提供非敏感错误类型。 |
| 有工具但调用报参数错误 | 按实际 schema 核对必填字段、日期和数量上限；不猜参数，不无限重试。 |
| 读取成功但缺阈值/训练日/恢复信息 | 保留缺口，给待确认草案，不编造完整处方或保存结果。 |

## 可选：让 AI 生成合并预览

`tools/workbuddy_mcp_preview.py` 仅生成私有合并预览和原字节备份，不改实时配置、不自动信任/授权。由本人指定已有只读 MCP 源条目；不同值冲突停止，重复生成保持幂等。先运行 `--help`，输出置于本人受限私有目录；保存到宿主前再次核对原文件未变化。普通用户优先按上方官方界面操作。

依据：[WorkBuddy 官方 Skill](https://open.workbuddy.cn/docs/skill)、[连接器与 OAuth](https://open.workbuddy.cn/docs/connector)。不承诺无需确认的一键部署。
